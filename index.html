About Weathermap

A premium weather experience, built with passion.

Project Description

Weathermap is a clean, modern weather dashboard that provides real-time weather data, hourly and 7-day forecasts, an interactive map, and air quality information — all wrapped in a premium dark-themed interface.

Features

  • Real-time current weather data
  • Hourly & 7-day weather forecasts
  • Interactive weather map
  • Air quality & UV index
  • Dark / Light theme switching
  • Geolocation support
  • Search any city worldwide
  • Fully responsive design

Technologies Used

  • HTML5 & CSS3
  • Vanilla JavaScript
  • OpenWeatherMap API
  • Leaflet.js
  • Font Awesome

Why This Project?

This was created as a personal learning project to explore working with APIs, asynchronous JavaScript, responsive design, and building a polished user interface from scratch.
